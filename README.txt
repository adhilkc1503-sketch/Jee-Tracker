# JEE AIR < 10 PWA

This is the PWA version of the JEE AIR < 10 Command Center.

Files:
- index.html — app
- manifest.webmanifest — install metadata
- sw.js — offline/service-worker support
- icon-192.png / icon-512.png — app icons

IMPORTANT:
A PWA must be served from HTTPS (or localhost during development) for service-worker installation.
After hosting these files at an HTTPS address, open the address in Chrome on Android and choose Install app / Add to Home screen.
